# CF USINAGEM

Sistema inteligente para auxílio em processos de usinagem CNC.

## Objetivo

Auxiliar operadores, programadores CNC, preparadores e engenheiros na seleção de parâmetros de corte, ferramentas e estratégias de usinagem.

## Funcionalidades Planejadas

- Login de usuários
- Aprovação de cadastro pelo administrador
- Cadastro de materiais
- Cadastro de máquinas CNC
- Cadastro de ferramentas
- Cálculo de RPM
- Cálculo de velocidade de corte
- Cálculo de avanço
- Estimativa de tempo de usinagem
- Análise de formação de cavacos
- Sugestões de melhoria de processo
